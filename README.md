# 衣伴 · 极简衣橱

「衣伴」是一款基于 uni-app 和 Vue 3 的个人衣橱与穿搭记录应用，主要面向微信小程序。你可以整理衣物、按天气获取穿搭建议，并记录每天穿过的单品。

## 功能

- **衣物管理**：添加、编辑、删除衣物，记录照片、品类、季节、颜色、风格、厚薄、购买价格和常穿标记。
- **分类与筛选**：按上装、下装、鞋子、配饰和适穿季节浏览衣物。
- **天气穿搭建议**：查询今天和明天的天气，支持当前位置、城市、经纬度或手动气温；根据衣橱单品生成搭配。
- **批量添加**：一次选择多张衣物照片；配置识别服务后可自动识别信息，也可手动填写。
- **穿搭日记**：用日历记录或计划穿搭，添加衣物、照片、场合和备注。
- **穿着统计**：查看穿着次数、连续记录、常穿排行、闲置衣物及单次穿着成本。
- **本地备份与偏好**：复制或恢复衣物和日记数据，设置节日提醒。

## 开发与运行

这是一个 uni-app 项目，仓库未配置 npm 脚本或独立的 CLI 构建流程，建议使用 HBuilderX：

1. 安装 HBuilderX（支持 uni-app / Vue 3），并安装微信开发者工具。
2. 在 HBuilderX 中导入本项目目录。
3. 如需运行到自己的微信小程序，在 `manifest.json` 的 `mp-weixin.appid` 中填写对应 AppID。
4. 在 HBuilderX 中选择运行到微信小程序模拟器；按提示配置微信开发者工具路径。也可选择 H5 运行进行预览。

项目的天气查询使用 Open-Meteo。发布微信小程序时，请在微信公众平台配置 `api.open-meteo.com` 为合法 request 域名；使用当前位置功能还需按微信平台要求配置位置权限和隐私声明。天气数据来源为 [Open-Meteo](https://open-meteo.com/)，遵循 CC BY 4.0。

## 可选：衣物照片识别服务

不配置服务时，批量添加仍可使用，但需要手动填写衣物信息。启用识别需要单独部署 Node.js 服务并配置视觉模型凭据：

1. 按 [server/README.md](server/README.md) 配置环境变量并启动服务（需要 Node.js 18 或更高版本）。
2. 将 `utils/config.js` 中的 `RECOGNIZE_URL` 设置为服务的 HTTPS 地址，例如 `https://你的域名/recognize`。
3. 将服务域名加入微信公众平台的合法 request 域名。

识别前应用会征求同意；同意后，所选照片会发送到识别服务及其配置的第三方视觉模型。识别服务代码不保存照片内容。请勿将模型密钥写入小程序代码。

## 数据与隐私

- 衣物、穿搭日记、设置及照片保存在当前设备；应用没有云端账户或自动同步功能。清除小程序数据或更换设备可能导致数据丢失。
- 「我的」页面可复制和恢复衣物及穿搭记录；备份不包含照片，照片需要在恢复后重新添加。
- 使用当前位置查询天气时，设备位置用于向天气服务查询天气；也可以改用城市、经纬度或手动填写气温。
- 批量识别会在用户同意后将照片发送到识别服务。请在部署服务前阅读并遵循 [识别服务说明](server/README.md)。

```text
├── manifest.json           # AppID、平台和权限配置
├── pages.json              # 页面路由与底部导航
├── pages/                  # 衣物库、分类、穿搭、日记、统计等页面
├── components/             # 衣物表单、卡片和穿搭记录表单
├── utils/                  # 本地存储、天气、照片、识别及统计逻辑
├── static/                 # 静态资源
├── types/                  # 数据类型声明
└── server/                 # 可选的衣物照片识别服务
```
